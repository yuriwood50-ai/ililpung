# 일일펑💥 (Ililpung)

매일 할 일을 **카드로 만들어 "펑!" 하고 폭파하는** 개인 루틴 웹앱이에요. 손그림 다이어리 느낌의 화면에 시스템 고딕 글꼴을 써서 단정하게 만들었어요. 서버·로그인 없이 브라우저에만 저장돼요.

## 목적

루틴 앱은 체크 표시만 누르면 끝이라 성취감이 약해요. 일일펑은 할 일을 끝낼 때마다 카드가 터지는 작은 보상을 주고, 기간별·항목별로 **성공과 미완료를 한눈에 돌아볼 수 있게** 만드는 게 목적이에요. 외부 라이브러리 없이 HTML·CSS·JS 파일 몇 개로 돌아가서 어디서든 열 수 있어요.

## 아키텍처

```text
 index.html ── 화면 뼈대 (오늘 / 기록 / 설정 3개 페이지, 할 일 편집 대화상자)
   ├─ styles.css        기본 레이아웃·카드·애니메이션
   ├─ diary-final.css   다이어리 디자인 덧입히기 (기존 스타일을 바꾸지 않고 위에 얹음)
   ├─ app.js            앱 전체 로직 (상태 · 계산 · 렌더링 · 이벤트)
   │     └─ localStorage  ililpung-v1 (할 일·완료 기록) / ililpung-sound-v1 (효과음 설정)
   ├─ sw.js             서비스 워커: 정적 파일 캐시 → 오프라인에서도 실행
   └─ manifest.webmanifest + assets/icon-*.png   홈 화면에 설치하는 PWA 정보
```

- **상태는 하나의 객체**(`state`)로 관리하고, 바뀔 때마다 localStorage 에 저장한 뒤 화면을 다시 그려요.
- **날짜는 로컬 기준 문자열**(`YYYY-MM-DD`)로 다뤄요. UTC 변환으로 날짜가 하루 밀리는 일을 피하려는 거예요.
- 할 일은 `periods`(활성 기간)와 `schedules`(반복 요일 이력)를 **덮어쓰지 않고 쌓아요.** 요일을 바꾸거나 보관·복원해도 과거 기록과 통계가 달라지지 않아요.
- 백업 파일을 가져올 때는 구조와 값 범위(항목 수, 글자 수, 날짜 형식)를 먼저 검사하고, 어긋나면 기존 데이터를 건드리지 않아요.

## 작동 방식

| 화면 | 하는 일 |
|---|---|
| **오늘** | 오늘 해야 할 카드가 시간순으로 나와요. 원형 **펑!** 버튼을 누르면 카드가 폭파되며 완료로 기록돼요. 효과음은 켜고 끌 수 있어요. |
| **기록** | 기간(오늘·주·월·직접 지정)과 항목을 골라 일·주·월 단위 막대 그래프와 추이를 봐요. 막대를 누르면 그날의 성공·미완료가 나와요. |
| **설정** | 할 일 추가·수정·보관·복원·삭제, 반복 요일과 시간 설정, 백업 파일 내보내기·가져오기. |

처음 실행하면 예시 할 일 4개가 들어 있어요. 마음대로 고치거나 지워도 돼요.

## 시작하기

Python 이 있으면 `일일펑_실행.bat` 을 더블클릭하세요. `http://localhost:8000` 이 열려요. (종료는 `Ctrl+C`)

```bash
python -m http.server 8000   # 또는 py -m http.server 8000
```

VS Code 의 Live Server 로 `index.html` 을 열어도 돼요. 서비스 워커와 PWA 설치는 `file://` 이 아니라 `localhost`나 https 에서만 동작해요.

### 홈 화면에 설치

브라우저 주소창의 설치 아이콘(또는 메뉴의 "앱 설치")으로 PWA 로 설치하면 독립 창으로 열리고 오프라인에서도 써요.

## 기록 보관

기록은 **이 브라우저의 localStorage 에만** 있어요. 브라우저 데이터를 지우거나 기기를 바꾸면 사라지니, 가끔 **설정 → 백업 파일 내보내기**로 JSON 을 내려받아 두세요.

## 알려진 한계

- 실제 브라우저에서의 화면 조작 시험은 자동화하지 못했어요. HTML 구조, 스타일 경로, 자바스크립트 문법은 확인했어요.
- 서버가 없어서 기기 간 동기화는 없어요. 백업 파일로 옮기세요.
